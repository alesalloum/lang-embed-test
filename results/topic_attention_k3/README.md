# Topic attention artifacts (K=3)

Generated by `scripts/cluster_user_attention.py` and
`scripts/plot_user_attention.py`.

## Files

| File | Description |
| --- | --- |
| `centroids.npy` | `(K, d)` L2-normalized KMeans centers |
| `train_config.json` | Fit config / seeds / paths |
| `post_assignments.jsonl` / `.csv` | Per-post hard label + soft weights |
| `user_attention_soft.*` | Per-user L1-normalized soft attention |
| `user_attention_hard.*` | Per-user L1-normalized hard attention |
| `qc_summary.json` | Cluster / user QC metrics |
| `topic_mass_*.png` | Global topic-mass bars |
| `user_attention_simplex_*.png` | Soft/hard user vectors on a 2D simplex |
| `umap_hard_clusters.png` | UMAP of 600 library posts, color = hard label |
| `umap_soft_clusters.png` | UMAP, color = soft-weight RGB blend |
| `umap_hard_soft_clusters.png` | Side-by-side hard vs soft |
| `umap_cluster_coords.jsonl` | UMAP x/y + hard/soft fields for library posts |

## Post assignment columns

`post_id`, `user_id`, `hard_label`, `soft_w0`, `soft_w1`, `soft_w2`
(plus `topic`, `language`, `source` when available).

## User attention columns

`user_id`, `n_posts`, `w0`, `w1`, `w2`, `assignment_type`
(`soft` or `hard`). Weights sum to 1.
